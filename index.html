🧠 DAA Algorithm

This application uses a Greedy Algorithm to select parcels with higher priority before lower-priority parcels.

Priority Score = (Urgency × 5) + (Deadline Priority × 3) - (Distance × 0.5)

How it works:

  • Read all parcel details.
  • Calculate a priority score for every parcel.
  • Higher urgency increases the priority.
  • Earlier deadlines increase the priority.
  • Shorter distances receive a small priority advantage.
  • Sort parcels by priority score.
  • Deliver the highest-priority parcel first.

Greedy Approach

At every step, the algorithm chooses the parcel that currently has the highest priority score. It does not need to calculate every possible delivery sequence.

Time Complexity

O(n log n)

Because parcels are sorted according to priority.

Space Complexity

O(n)

Because the parcel list and schedule are stored.
